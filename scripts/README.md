# Scripts

## check_links.py

Scans repository text files for URLs and checks whether they respond successfully.

Run:

```bash
python scripts/check_links.py
```

## build_catalog.py

Converts the JSON certification catalog into a CSV file.

Run:

```bash
python scripts/build_catalog.py
```

Use these scripts for repository maintenance only. Security-testing scripts should be used only in systems and environments you are authorized to test.

# EC-Council Certified Ethical Hacker (CEH v13) Exam Resources & Study Guide

This document aggregates key study notes, tool syntax references, and preparation strategies for the **EC-Council Certified Ethical Hacker (CEH v13) - 312-50 v13** exam.

---

## 📌 Core Domain & Methodology Breakdown

To pass the CEH v13 exam, candidates should master the standard 5-phase ethical hacking methodology and modern attack vectors:

1. **Footprinting & Reconnaissance**: Open Source Intelligence (OSINT), WHOIS lookup, Google dorking, and DNS enumeration.
2. **Scanning Networks**: Master Nmap flags (`-sS`, `-sV`, `-O`, `-sU`), Wireshark display filters, and vulnerability scanning mechanics.
3. **Enumeration & System Hacking**: NetBIOS, SNMP, LDAP, and SMB enumeration; password cracking methods, privilege escalation, and steganography.
4. **Web & Wireless Security**: OWASP Top 10 vulnerabilities (SQLi, XSS, CSRF), Wi-Fi encryption protocols (WPA2/WPA3 enterprise), and web proxies (Burp Suite).
5. **v13 Modern Vectors**: AI-driven threat intelligence, IoT/OT security protocols, Docker container breakouts, and Cloud IAM misconfigurations.

## 💡 Practical Preparation Tips

* **Tool Switches are Critical**: Ensure you memorize command-line options for common security tools like Nmap, tcpdump, and John the Ripper.
* **Understand the Sequence**: Always answer scenario questions based on the official pentesting phase order (Reconnaissance -> Scanning -> Enumeration -> Hacking -> Covering Tracks).
* **Pacing**: With 125 questions over 240 minutes, you have nearly 2 minutes per question. Read carefully for keywords like "FIRST step" or "LEAST likely".
